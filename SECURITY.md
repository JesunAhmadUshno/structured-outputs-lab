# Security policy

Report a vulnerability privately through GitHub's "Report a
vulnerability" button on this repository's Security tab. Please do not
open a public issue for it. You will get a reply within 7 days.

Scope: the code in this repository and the static dashboard in site/.
The Python code uses the standard library only, makes no network call
and reads no credential; the dashboard runs entirely in the browser.
No credential is stored in this repository.
